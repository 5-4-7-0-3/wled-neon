# WLED Neon

Мінімальний пульт для LED-неону на контролері [WLED](https://kno.wled.ge/), без нічого зайвого.

- **Windows**: значок у треї, що світиться кольором неону; лівий клік відкриває панель, правий — меню (увімкнути/вимкнути, автозапуск, вихід). Стартує разом із Windows.
- **Android**: той самий пульт як звичайний застосунок.

У панелі лише: живлення, яскравість, колір (смуга відтінків + 10 готових), 8 режимів і їх швидкість.

Прошивку контролера не змінює: працює через стандартний JSON API та WebSocket WLED, тож зміни з телефона й ПК синхронізуються миттєво.

## Встановлення

Готові `.exe` і `.apk` — у [Releases](../../releases).

Адреса контролера за замовчуванням — `192.168.1.12`. Змінити її можна, натиснувши на крапку зʼєднання біля назви.

## Розробка

Потрібні Node 20+, для Android — Android Studio (JDK 21, Android SDK).

```bash
npm install
npm run dev            # панель + Electron з hot reload
npm run dist:win       # інсталятор release/Neon Setup *.exe
npm run dist:android   # android/app/build/outputs/apk/debug/app-debug.apk
npm run icons          # перегенерувати іконки
```

| Тека | Що всередині |
|---|---|
| `src/` | спільний інтерфейс (React): панель і клієнт WLED |
| `electron/` | трей, вікно-панель, автозапуск, генератор іконок |
| `android/` | проєкт Capacitor |
| `scripts/` | генерація іконок для Windows і Android |
